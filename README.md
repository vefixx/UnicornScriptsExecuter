# UnicornScriptsExecuter
Консольное приложение на C# для автоматического выполнения SQL-скриптов. Создан для отработки архитектурных паттернов, работы с данными и логирования в .NET. Является учебным проектом, входит в реализацию учебного проекта от ООО «Юникорн»

## Аналог
Для простого запуска скрипта достаточно использовать одну строку в cron:
```cmd
0 * * * * sqlite3 /path/to/db.db < /path/to/script.sql
```

Но данный проект создан не для замены bash-скриптов, а как учебная площадка для:
- Парсинга командной строки запуска
- Изучения работы с `Dapper`
- Изучение логирования с помощью `Serilog`
- Конфигурация приложения (через `Microsoft.Extensions.Configuration` c `Binder`)

## Возможности
Скрипт может:
- Автоматически выполнять все **.sql** файлы из указанной директории
- Гибко настраивать конфигурацию, а именно - путь к скриптам и строка подключения
- Структурированно логировать через `Serilog`
- Транзакционно выполнять скрипт, чтобы при возникновении ошибки делать откат

## Технологии
- `Dapper` - микро-ORM для выполнения SQL
- `Microsoft.Data.Sqlite` - провайдер для SQLite (для подключения к БД)
- `Serilog` - логирование с разными выходами (консоль, файл)
- `CommandLineParser` - парсинг аргументов

*Проект заточен под базу данных **SQLite**, но может быть адаптирован под любую другую, которую поддерживает `Dapper`*.

## Настройка
### 1. Файл конфигурации `appsettings.json`
Создайте файл в корне проекта:
```json
{
  "AppSettings": {
    "ConnectionString": "Data Source=./data/database.db",
    "QueriesPaths": {
      "daily": "./Scripts/Daily",
      "hourly": "./Scripts/Hourly",
      "weekly": "./Scripts/Weekly"
    }
  }
}
```

| Параметр | Описание |
|:--------:|:--------:|
| `ConnectionString` | Строка подключения к вашей БД |
| `QueriesPaths` | Словарь: `ключ` = тип обновления (для --type), `значение` = путь к папке со скриптами |

## Запуск
### Командная строка
```cli
Базовый запуск
dotnet run --type <type>

С логирование в файл
dotnet run --type <type> --with-file-logging

<type> - тип запуска
```
